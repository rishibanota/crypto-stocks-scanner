# Contributing

Thank you for your interest in contributing to **Live Market Screener**! This project is a community-driven open-source tool, and we welcome contributions of all kinds.

## How to Contribute

### Reporting Bugs

- Search existing issues to avoid duplicates.
- Open a new issue using the **Bug Report** template.
- Include steps to reproduce, expected vs actual behavior, and your environment (browser, OS).

### Suggesting Features

- Open a new issue using the **Feature Request** template.
- Describe the feature, why it would be useful, and any implementation ideas you have.

### Code Contributions

1. Fork the repository and clone your fork.
2. Create a new branch for your change: `git checkout -b feature/your-feature-name`.
3. Make your changes to `index.html`.
4. Test the changes locally by opening `index.html` in a browser.
5. Commit with a clear, descriptive message.
6. Push to your fork and open a pull request using the PR template.

### Style Guidelines

- Keep changes minimal and focused.
- Follow existing code style in `index.html`.
- Avoid introducing external frameworks or dependencies.
- Ensure the app still loads and functions correctly after changes.

## Questions?

Feel free to open an issue for any questions or discussions about the project.
